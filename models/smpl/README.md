Place the official SMPL model files here (not included in the repo).

Download the SMPL model from the SMPL website or your licensed provider and place the appropriate
`basicModel_f_lbs_10_207_0_v1.0.0.pkl` or `basicModel_m_lbs_10_207_0_v1.0.0.pkl` inside this folder.

Example:
models/smpl/basicModel_f_lbs_10_207_0_v1.0.0.pkl

The `twin_generator.py` script expects this directory as `models/smpl` by default.
